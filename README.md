# 🧪 Calculadora de Massas

Calculadora web desenvolvida para auxiliar em cálculos químicos de análises de amostras.

O projeto permite informar os dados da amostra e da titulação e gerar automaticamente os cálculos de:

- Densidade da amostra
- Mols de Na₂S₂O₃
- Quantidade de Cl₂
- Massa de Cl₂
- Média das massas
- Porcentagem em massa/massa (m/m)
- Porcentagem em massa/volume (m/V)

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript
